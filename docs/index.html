A filled dot and a ring are two entries of one tool, such as two models.

How a number is made

  1. Test cases in

    A tool hands in the test cases that its runs generated.

  2. One pinned replay

    One gcov build of each program, pinned, replays the test cases.

  3. Branch sets out

    Each run leaves the set of branches it reached.

Tasks

  • Read the results

    Median coverage of every tool on every program, as a table.

  • Compare two tools

    Two tools side by side on the programs both ran on.

  • Submit a tool

    For authors of a test generator who want it measured beside these.

  • Check the release

    Its name, date, counts and what it was measured with.
