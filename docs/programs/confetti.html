Confetti

1.0.0-beta.4
Terms
Run
One campaign of one tool on one program.
Cores
The parallel processes of one campaign.
Budget
The longest a campaign may run.
Fixed track
The command line is given and the tool supplies only the input. Method
Open track
The tool also chooses arguments, files and environment. Method
Median
The middle value over a tool's runs; the median of two runs is their mean.
standard
Conventional gcov replay of every retained test case, same counting code and denominators. Method
Unreached
A branch that none of the main-group tools that ran on the program reaches (4 to 12 tools).
Union of runs
The branches that at least one of a tool's runs reaches, each counted once.
Output tokens
Model output of a whole campaign, reasoning included, as self-reported in the release.
Sanitiser signature
The sanitiser, the error kind and the innermost frame in the program's own source; two can share a cause.
Language model
A system in which a language model does the central reasoning of a classical technique, such as concolic execution.
Symbolic
Runs the program on symbolic inputs and asks a constraint solver for concrete inputs that reach new paths.
Fuzzer
Coverage-guided fuzzing: mutates inputs and keeps those that reach new code.
Hybrid
A fuzzer paired with a concolic executor; each supplies the other with inputs.
Main
Shown by default: the tools a reader is most likely to compare.
Ablation
Variants of the agent that switch off or change one part, to show what that part adds.
Seeding
Runs of a tool that start from seeds produced by another system.
Control
Systems that run without the agent, as a reference for the main group.
Release
A dated snapshot of the data, named like 2026.1. It never changes; corrections go into the next release.
Superseded
An entry that a newer one replaces. It stays in the release and shows under all versions.
Withdrawn
An entry taken out of the comparison after it was published.
