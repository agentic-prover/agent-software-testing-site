Coverage
Each tool’s test cases are replayed and counted on the branches of one pinned gcov build per program. Every replay runs in a container that sees only its own processes.
Runs
† marks fewer than {{min_repeats_word}} runs. A run lasts {{budget_hours_word}} hours by default (other budgets labelled). Tables show medians.
Tracks
On the fixed track the tool supplies only the input to a fixed command line; on the open track it also chooses arguments, files and environment. Results on different tracks do not compare; budgets and cores change what a result means.

Limits
A crash or timeout writes no coverage. A model may have seen the programs. Of {{systems}} entries, {{n_agent}} are variants of the maintainers’ agent, Agolic.{{n_agent_seeds_clause}} The maintainers ran, configured or ported every baseline. Budgets, cores and tokens are self-reported. Coverage counts the branches that test cases reach. A sanitiser signature is an untriaged report.
